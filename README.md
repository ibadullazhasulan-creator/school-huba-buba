# CLASSVERSE Neon 3D

Заманауи интерактивті 3D мектеп платформасы.

## Ерекшеліктері
- Three.js негізіндегі неон 3D кампус
- Бөлмелерге "Кіру" батырмасы арқылы өту
- Smart Classroom, STEM / AI Lab, Neon Library, Event Hall
- Анимацияланған жарықтар, бөліктер, фон эффектілері
- Ашық неон glassmorphism дизайн
- GitHub Pages-ке жариялауға дайын

## Іске қосу
1. Папканы VS Code-та ашыңыз.
2. `index.html` файлын Live Server арқылы іске қосыңыз.
3. Немесе GitHub репозиторийіне жүктеп, Pages қосыңыз.

## GitHub Pages
- Settings → Pages
- Deploy from a branch
- Branch: `main`, folder: `/root`

Содан кейін сілтеме мынадай болады:
`https://USERNAME.github.io/REPOSITORY_NAME/`
