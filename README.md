# CLASSVERSE NEON 3D — автономды жұмыс істейтін нұсқа

## Негізгі түзету
Алдыңғы нұсқаның 3D сахнасы браузерде жүктелмеуінің себебі Three.js OrbitControls импортында `three` модулі анықталмағаны болды. Жаңасында бұл мәселе жоқ: 3D перспектива **таза JavaScript + Canvas** арқылы құрастырылған, CDN тәуелділігі жоқ.

## Нақты функциялар
- Бірден көрінетін 4 3D нысан: Smart Classroom, STEM / AI Lab, Neon Library, Event Hall.
- Әр нысанда **Кіру** батырмасы: әрқайсысында бөлек 3D интерьер (парталар, колбалар, сөрелер, сахна).
- Кампус модельдерін тінтуір арқылы айналдыру және жақындату.
- Ғимаратқа басқанда ақпарат және бөлмеге кіру түймесі.
- Кампусқа қайту батырмасы және Escape пернесі.
- Ашық неон, glow, анимацияланған декор және responsive интерфейс.

## VS Code / GitHub Pages
1. Папкадағы `index.html`, `style.css`, `script.js` файлдарын бір папкада сақтаңыз.
2. VS Code-та `index.html` файлын Live Server арқылы ашыңыз (не файлды браузерде тікелей ашыңыз).
3. GitHub-қа осы файлдарды жүктеп, **Settings → Pages → Deploy from a branch → main → /(root)** таңдаңыз.
4. Бірнеше минуттан кейін `https://USERNAME.github.io/REPO/` бойынша ашылады.

Қосымша: Google Fonts интернетпен жүктеледі, бірақ сайттың негізгі көрінісі оларсыз да жұмыс істейді.
